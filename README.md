# X7 图文打印工作室 (X7PrintStudio)

在 PC 上**组合图像与文字并直接打印**到 得力相印宝 X7(热敏打印标签机) 的专用图文编辑器。
有 **USB 线**即可打印 —— 无需蓝牙、无需官方手机 App。

- 原生幅宽画布 **1248px @300dpi(≈105mm 连续纸)**,所见即所打。
- 图层式图文排版:插图片 / 插文字,点选拖拽、图片四角缩放,文字可双击编辑。
- **剪贴板直贴**:截图或文字直接 `Ctrl+V`(或工具栏“粘贴”)入画布,免去存文件再插入。
- 每张图的**图像处理开关**:原图灰阶 / 黑白高对比(阈值可调)/ 反白;文字可反白用于深色底。
- 打印预估(纸长 mm + 墨量%)、份数、打印队列选择;**也可仅导出作业 `.bin`**(供其它通道如蓝牙桥再发)。
- 工程保存/打开(`.x7proj`)、导出灰度 PNG。

## 运行

1. 从 **Releases** 下载 `X7PrintStudio.exe`(单文件,免安装、免 Python),解压后双击即可运行;
   Windows 提示“未知发布者”时,选 **更多信息 → 仍要运行**(应用未签名,属正常)。
2. 首次使用:**用 USB 线把 X7 接到电脑**,Windows 会自动建好打印队列「得力X7相印宝」(端口 USB00x),程序内即可直接打印。
3. 不接打印机也能启动,用于排版、预览与导出作业 `.bin`。

## 用法

1. 启动程序(见上「运行」)进入编辑窗口。
2. `＋图片` 插单张照片、`批量图片…` 一次选多张自动网格排版、`＋文字` 写字;拖动/缩放排版,右侧属性面板微调字号/处理模式。
3. 点 **打印/导出作业…** → 预览纸长与墨量 → 打印(或导出 .bin)。
4. 首次打印建议先在设置里选好 **1bpp效果** 预览,确认排版密度合适再出纸。

> 连续纸打印:画布高度即"纸长",内容到底会自动加长画布,整段一次性出纸。

## 打印原理(说明)

X7(得力相印宝)内部走 **HPRT 协议**,逐字节验证要点(详见下方"兼容与限制"):

- 栅格:**1 bit = 黑 = 加热**;行宽 1248px = 156B;每帧 ≤ 16 行。
- 帧 = `1D 76 30 30 | 156LE16 | 行数LE16 | 压缩长LE32 | 载荷`;
  载荷 = **原生 libLZO 风味压缩**(`lzo.compress(raw)` 去掉 5 字节 minilzo 前导),固件按定长解压。
- 作业明文序:设备查询 → 参数(`浓度 p0 / 速度 s10 / 幅宽 w1248`)→ 栅格帧段 → 走纸 feed。
- 灰度图先经 **Floyd–Steinberg 抖动**到 1bpp(热敏机表现比连续灰阶稳)。
- **USB 通道**:Windows 把它当普通打印机(Class 07/01/02,usbprint 驱动,免装驱动)。
  本软件向该队列以 **RAW 数据类型原样写入**明文作业,spooler 零渲染,逐字节送达打印机 —— 与蓝牙 SPP 传输
  的 `set mm` 握手 + XOR 无关(SPP 专属,USB 不需要)。

### 兼容与限制(如实)

- 颜色打印 = **灰度 + 抖动**(热敏物理限制,单色黑)。
- 幅宽 ≈105mm:A4 等宽文档会缩印到一半左右,请按本软件原生幅宽排版,
  推荐用于 **照片 / 票券 / 标签 / 窄幅图文**。
- 黑底 = 整面加热打印,耗墨(热敏纸)明显,仅在需要"反白文字深底"视觉时用。
- 深色照片直接用"黑白高对比"档通常比灰阶更清晰,墨量更省。

## 仓库说明

本软件为独立、自包含的编辑器工程,不含任何第三方驱动或闭源组件,依赖均为 pip 常见库
(PySide6 / Pillow / python-lzo / pywin32 / numpy)。协议结论来自对用户自有 X7 打印机配套
官方 App(安卓)的逆向与真机打印比对,仅用于本机互操作。
